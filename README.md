# مساعد المكالمات الصوتي - Version 1 (MVP)

## المميزات في النسخة دي
1. **نطق اسم المتصل** بصوت عالي لما تيجي مكالمة (لو الرقم محفوظ يقول الاسم، لو مش محفوظ يقول الرقم)
2. **الاتصال بالأمر الصوتي**: قول "يا مساعد" واستنى، بعدين قول "اتصل على أحمد" أو "اتصل على 01012345678"
3. **حفظ رقم جديد بالصوت**: أثناء مكالمة جارية قول "يا مساعد" ثم "سجل الرقم ده باسم محمد"
4. **الرد/الرفض الصوتي**: لما تيجي مكالمة، قول "يا مساعد" ثم "رد" أو "ارفض"

## ⚠️ خطوة لازمة قبل أي حاجة: gradle-wrapper.jar
المشروع فيه `gradlew` و`gradlew.bat` و`gradle-wrapper.properties`، لكن
ملف `gradle-wrapper.jar` نفسه (ملف باينري) مش موجود لأني عملت المشروع من
غير إنترنت. الحل بسيط جدًا - اختار واحدة:
- **الأسهل**: افتح المشروع في Android Studio عادي، هو هيلاحظ نقصه ويعرض
  زرار "Sync" يضيفه تلقائيًا، أو من القائمة: File > Sync Project with Gradle Files
- **أو من التيرمنال** (لو عندك gradle مثبت جهازك): `gradle wrapper --gradle-version 8.7`
- ده مطلوب مرة واحدة بس، وبعدها `gradlew` هيشتغل عادي في أي CI/CD زي GitHub Actions

## خطوات التشغيل

### 1. فتح المشروع
- افتح Android Studio (أحدث نسخة)
- File > Open > اختر فولدر CallAssistant
- سيب Gradle يعمل sync (محتاج إنترنت أول مرة)

### 2. تشغيل التطبيق
- وصل موبايل حقيقي (مش إيموليتور، لأن المكالمات والصوت محتاجين جهاز حقيقي)
- فعّل Developer Options + USB Debugging على الموبايل
- اضغط Run

### 3. الإعداد داخل التطبيق
لازم تعمل الخطوات دي بالترتيب من شاشة التطبيق:
1. اضغط **"اعطِ الصلاحيات"** ووافق على كل حاجة
2. اضغط **"اجعله تطبيق الاتصال الافتراضي"** ووافق (ده أهم خطوة - من غيرها الرد/الرفض مش هيشتغل)
3. اضغط **"شغّل المساعد الصوتي"**

## ملاحظات مهمة جدًا

- **بدون ما تخليه Default Dialer**: هيشتغل نطق اسم المتصل + الاتصال بالأمر الصوتي بس. الرد/الرفض مش هيشتغل.
- **كلمة التنبيه** حاليًا هي "يا مساعد" - تقدر تغيرها من `VoiceAssistantService.kt` سطر `WAKE_WORD`
- الاستماع المستمر للصوت (Wake Word) بيستهلك بطارية ملحوظ - في نسخة لاحقة الأفضل نستخدم Porcupine أو مكتبة wake-word متخصصة بدل SpeechRecognizer العادي
- بعض الموبايلات (Xiaomi, Huawei, Samsung بالذات) بتوقف الخدمات اللي شغالة بالخلفية تلقائيًا - محتاج تضيف التطبيق لقائمة "Battery - No restrictions" يدويًا من إعدادات الموبايل
- التعرف على الصوت العربي مش مثالي 100% خصوصًا باللهجة المصرية - جرب تتكلم بالفصحى المبسطة لو النظام مش فاهم

## الذكاء الاصطناعي (اختياري)
لو تحليل الأوامر المحلي (regex) فشل يفهم جملة معينة، البرنامج يبعتها
تلقائيًا لـ Groq API (مجاني بالكامل) كخطة بديلة. الخطوات:
1. اعمل حساب مجاني على https://console.groq.com (بالإيميل، بدون كارت ائتمان)
2. من API Keys اعمل مفتاح جديد وانسخه
3. افتح `app/src/main/java/com/example/callassistant/Config.kt`
4. حط المفتاح في `GROQ_API_KEY = "المفتاح هنا"`
5. ابني المشروع تاني

لو سبت المفتاح فاضي، البرنامج يشتغل عادي بالتحليل المحلي بس بدون AI.

## ملاحظة أمان
متحطش مفتاح الـ API في كود عام على GitHub (public repo) - أي حد هيقدر ياخده
ويستخدمه على حسابك. لو الريبو public، استخدم GitHub Secrets وتمريره وقت
البناء بدل ما تكتبه في الكود مباشرة.


```
MainActivity.kt          - الشاشة الرئيسية وطلب الصلاحيات
VoiceAssistantService.kt - قلب المساعد: الاستماع المستمر وتنفيذ الأوامر
InCallServiceImpl.kt     - التحكم الفعلي في المكالمة (رد/رفض) - يتطلب Default Dialer
CallScreeningServiceImpl.kt - فلترة المكالمات (جاهزة للتوسع لاحقًا لحجب أرقام)
PhoneStateReceiver.kt    - يكتشف المكالمة الواردة وينطق اسم المتصل
ContactsHelper.kt        - البحث/الحفظ في جهات الاتصال والاتصال بالأرقام
TTSHelper.kt             - تحويل النص لصوت
BootReceiver.kt          - يشغل الخدمة تلقائيًا بعد إعادة تشغيل الموبايل
```
